# PRD — Tasbih Counter (광고 없는 타스비 카운터, 앱 #003)

> 채우는 시간: 30분 이내. 이후 코딩 단계에서 이 문서가 계약이다.
> 상태: **초안 — 인간 승인 대기**

## 1. 목적·타깃
- **문제**: 디지털 타스비(염주) 앱으로 지크르(dhikr)를 세는 무슬림들이 기도 중에 뜨는 광고(도박·선정적 광고 포함)와 광고 오터치로 인한 카운트 초기화 때문에 불편하다.
- **타깃 사용자**: 매일 지크르·기도 후 타스비(33/33/33)를 세는 무슬림 사용자 (안드로이드 중심)
- **지역/언어**: 인도네시아·말레이시아·터키·중동 — **en(기본) / id / tr / ar(RTL)** + 검수 편의용 ko
- **수요 증거 링크** (`../_candidates/2026-09-26-candidates.md` #2):
  - [V] https://apps.apple.com/us/app/tasbih-counter-lite-dhikr-app/id1501329079 — "광고가 부적절해 삭제", "광고 오터치로 40,000+ 카운트 리셋"
  - [V] https://play.google.com/store/apps/details?id=com.muslimidia.tasbih — 10만+ 다운로드, "광고가 너무 많음"
  - [S] https://play.google.com/store/apps/details?id=com.sevapp.smart_tasbeeh — "지크르 중 도박·여성 모델 광고"
  - [S] https://apps.apple.com/us/app/tasbih-counter-pro-dhikr-app/id1341100401 — "Pro 결제했는데도 광고"

**차별화 한 줄**: "광고 0, 추적 0, 카운트 절대 안 날아감."

## 2. 핵심 기능 (5개)
- **F1 큰 탭 카운터**: 화면 대부분이 탭 영역. 탭마다 진동, 목표 도달 시 긴 진동 + 시각 표시. **-1(되돌리기)** 버튼. **초기화는 길게 누르기 + 확인창**(오터치 리셋 방지). 탭할 때마다 즉시 저장(앱 종료·재시작해도 카운트 유지). 화면 켜짐 유지 옵션.
- **F2 지크르 프리셋 + 목표**: 기본 프리셋 — SubhanAllah 33 / Alhamdulillah 33 / Allahu Akbar 34(또는 33+1) 연속 모드(기도 후 타스비, 목표 도달 시 자동 다음 단계), 단일 지크르(목표 33/99/100/무제한). 각 프리셋에 아랍어 원문 + 로마자 음역 + 선택 언어 뜻 표시. 사용자 정의 지크르 추가(이름·목표).
- **F3 기록·연속일**: 일별 총 횟수, 지크르별 합계, 최근 30일 막대 차트, 연속일(streak).
- **F4 설정**: 언어(en/id/tr/ar/ko, 아랍어 RTL), 라이트/다크, 진동 on/off, 소리 on/off(기본 off), 화면 켜짐 유지, 데이터 백업/복원(JSON).
- **F5 Pro(1회 결제)**: 사용자 정의 지크르 무제한(무료 3개), 기록 CSV 내보내기, 테마 색상. → 시범 빌드는 **테스트 토글**(001과 동일 방식), 실제 결제는 Play Billing 연동 시점에.

> 범위 밖(이번 버전 제외): 볼륨키 카운트, 홈 화면 위젯, 기도 시간·키블라 방향(위치권한·계산 책임), 꾸란 본문.

## 3. 화면 목록 (웹/PWA + 안드로이드 공통 단일 UI, 하단 탭 3개)
- **카운터**: 현재 지크르 이름(아랍어·음역·뜻) / 큰 숫자 / 진행 링(목표 대비) / 탭 영역 / -1 · 초기화(길게) · 지크르 바꾸기
- **지크르 목록**: 프리셋 + 사용자 정의, 추가/편집/삭제, 선택 시 카운터로
- **기록**: 오늘 합계 · 연속일 · 30일 차트 · 지크르별 합계
- **설정**(기록 탭 상단 아이콘 또는 별도 화면): F4 항목 + Pro + 개인정보방침 링크
- 첫 실행: 언어 자동 감지(브라우저/기기 언어) 후 1장짜리 안내

## 4. 데이터 모델
- 저장: **localStorage 전용** (서버·계정·분석 SDK 없음)
- 주요 필드:
  - `dhikrs[]`: `{ id, preset: boolean, arabic, translit, meaningKey | customName, target: number | null, sequence?: id[] }`
  - `session`: `{ dhikrId, count, step(연속 모드 단계), updatedAt }` — 탭마다 저장
  - `history`: `{ 'YYYY-MM-DD': { [dhikrId]: count } }` — 일별 누적
  - `settings`: `{ lang, theme, vibrate, sound, keepAwake, pro }`
- 백업: 위 전체를 JSON 1파일로 내보내기/가져오기

## 5. 수익화
- 광고 위치: **없음 — 영구 무광고** (광고 자체가 경쟁앱의 핵심 불만. 템플릿의 AdMob 훅은 비활성 유지, 스토어에 "광고 없음" 명시)
- 결제 항목: **Pro 1회 결제** (F5) — 가격 가설 $1.99~2.99 (현지 가격 자동 환산). 시범 빌드는 테스트 토글
- 웹: PWA로 바로 사용 가능 + "안드로이드 앱 받기" CTA(상장 후 링크)

## 6. Play 정책 체크
- 개인정보방침 URL: `public/privacy.html` — "데이터는 기기에만 저장, 수집·전송 없음" (상장 전 실제 연락처로 교체)
- 광고 포함 신고: **아니요** (광고 미포함)
- 데이터 안전 양식: 수집 데이터 없음
- 콘텐츠 등급(IARC): 상장 단계에서 진행 (종교 콘텐츠 — 폭력·도박 없음)
- 디지털 상품 결제 시 Play Billing 사용: ☑ Pro는 Play Billing 필수 (시범 빌드는 결제 미연동, 테스트 토글만)
- 종교 콘텐츠 정확성: 프리셋 아랍어 문구는 널리 쓰이는 표준 지크르만 사용, 번역은 상장 전 원어민 검수 권장

## 7. 검증 기준
- 자동: `npm run build` 성공, 단위 테스트(카운트·목표 도달·연속 모드 단계 전환·일별 기록 집계·백업 왕복), `scripts/smoke_check.ps1` PASS (Windows 필요 — 이 환경에선 "검증 불가"로 표기)
- 대조: F1~F5 각각 브라우저(Playwright, 모바일 뷰포트)에서 실제 동작 확인 — 특히 **새로고침 후 카운트 유지**, **초기화 오터치 방지**, **아랍어 RTL 레이아웃**
- 주관: 실기기 스모크(진동·화면 켜짐 유지는 기기에서만 확인 가능) + UX — 인간 검수, 별도 세션
