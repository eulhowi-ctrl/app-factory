# PRD — Symptom Diary (만성질환 증상 다이어리)

> 시범 앱 #1. 게이트: 이 PRD 승인 후 코딩 시작. 미완성 항목이 있으면 코딩으로 넘어가지 않는다.

## 1. 목적·타깃
- **문제**: 루푸스·크론병·섬유근통 등 만성질환 환자가 증상을 매일 기록하고 **의사 면담 때 정리된 요약을 보여줄** 도구가 없다. 기존 앱은 월구독+클라우드 계정을 강제한다.
- **타깃 사용자**: 만성질환을 앓는 성인 (영어권 우선)
- **지역/언어**: 영어 기본. 추가 언어는 2차 반복에서.
- **수요 증거**: `apps/_candidates/2026-08-10-candidates.md` #1 — [nichemetric](https://www.nichemetric.com/blog/how-to-find-profitable-app-niches-2026) · [fridayaiclub](https://fridayaiclub.com/i-scraped-42-platforms-so-you-dont-have-to-5-underrated-saas-ideas-for-2026/)

## 2. 핵심 기능 (5개 이하)
- **F1 증상 기록**: 날짜·시간별 증상 추가 (이름, 강도 1~10, 메모). localStorage 저장.
- **F2 약물 기록**: 복용 약물·용량·시간 로그.
- **F3 타임라인**: 선택 기간의 증상·약물을 시간순 표시.
- **F4 의사 공유 내보내기**: 기간 선택 → **CSV 다운로드(네이티브)** + **PDF 인쇄(print CSS, 추가 의존성 없음)**. 증상 빈도·강도 요약 포함.
- **F5 프리미엄(유료)**: 기간 비교 통계 + 광고 제거. 1회 구매.

## 3. 화면 목록
- 홈: 오늘 요약 + 빠른 증상 추가
- 기록: 증상/약물 추가 폼
- 타임라인: 기간별 보기
- 내보내기: 기간 선택 → CSV/PDF
- 설정: 프리미엄 해금, 데이터 내보내기/지우기

## 4. 데이터 모델
- `localStorage`: `symptoms[]` {id, date, name, severity(1-10), note}, `meds[]` {id, name, dose, time, date}
- 서버 불필요. 웹/안드로이드 동일 저장소.
- 의료 데이터이므로 **수집/전송 없음** 명시 (개인정보방침 핵심).

## 5. 수익화
- 광고: 하단 배너 (안드로이드 AdMob, `src/ads.ts`)
- 결제: **"광고 제거 + 통계" 1회 IAP** (Play Billing) — 구독 아님
- 웹: 무료 도구로 유입 → 안드로이드 CTA 퍼널

## 6. Play 정책 체크
- 개인정보방침 URL: `public/privacy.html` (로컬 저장만, 수집 데이터 없음 명시)
- 광고 포함 신고: ☑ (AdMob)
- 콘텐츠 등급(IARC): 상장 단계에서 진행
- 데이터 안전성: 로컬 전용, 수집·전송 없음
- **의료 고지 필수**: "의료 진단·치료 조언이 아닌 기록 도구임" 문구를 앱 내 표시

## 7. 검증 기준
- 자동: `scripts/smoke_check.ps1` PASS
- 대조: F1~F5 각각 실제 동작 (증상 기록 → 타임라인 → CSV/PDF 내보내기)
- 주관: 실기기 스모크 + UX 확인 (의료 고지 노출 확인)
