# PRD — Jigsaw Puzzle

> 채우는 시간: 30분 이내. 이후 코딩 단계에서 이 문서가 계약이다.

> **재작성 이력**: 이 앱은 최초 Flutter로 구현되었다가, "표준 템플릿(react-vite-capacitor)에
> 맞춰 다시 만들어달라"는 요청에 따라 **React + Vite + Capacitor로 전체 재구현**했다.
> 조각 생성 엔진(요철 곡선, 격자 레이아웃)은 Flutter판과 동일한 알고리즘을 TypeScript로
> 이식했고, 렌더링은 SVG clipPath로 대체했다.

## 1. 목적·타깃
- **문제**: 심심할 때 가볍게 시간 보낼 캐주얼 직소 퍼즐 게임이 필요하다
- **타깃 사용자**: 캐주얼 퍼즐 게임을 즐기는 일반 사용자 (연령 무관)
- **지역/언어**: 영어 기본(해외 틈새 대상, 공장 방침) + 한국어 지원
- **수요 증거 링크**: (없음 — 소재는 대화 중 인간이 직접 지정: "퍼즐 → 직소 퍼즐")

## 2. 핵심 기능 (5개 이하)
- F1: 난이도 선택 (20 / 54 / 96 / 150 피스 — 1000피스는 모바일 터치 조작 부담으로 제외)
- F2: 이미지 선택 (앱 기본 번들 사진 3장 — Picsum/Unsplash 무료 라이선스)
- F3: 실제 요철(탭/블랭크) 모양의 직소 조각 — SVG clipPath로 렌더링, 드래그 & 정답 스냅
- F4: 핀치줌/팬(2손가락 확대·1손가락 이동)으로 큰 피스 수도 조작 가능, 데스크톱은 휠 줌
- F5: 완성 시 소요시간 표시 (조각수/경과시간 상단 표시, 완료 다이얼로그)

## 3. 화면 목록
- 홈 화면: 이미지 3장 그리드 선택 + 난이도 칩 선택 + 시작 버튼
- 퍼즐 화면: 보드 영역 + 흩어진 조각(트레이) + 상단 진행률/타이머

## 4. 데이터 모델
- 저장: 없음 (세션 내 메모리 상태만, 서버 불필요)
- 조각 레이아웃은 매 판 결정적 생성 가능(seed 지정 시 재현) — `src/engine/puzzleGenerator.ts`

## 5. 수익화
- 광고 위치: 미구현 (MVP는 무료 플레이만). AdMob 훅(`src/ads.ts`)은 템플릿 그대로 유지 —
  네이티브(Capacitor) 빌드에서만 초기화되고 웹에선 no-op
- 결제 항목: 없음
- 웹: 정적 배포로 바로 플레이 가능 (Cloudflare Pages 등)

## 6. Play 정책 체크
- 개인정보방침 URL: `public/privacy.html` (상장 전 실제 연락처로 교체 필요)
- 광고 포함 신고: 해당 없음 (광고 미포함)
- 콘텐츠 등급(IARC): 상장 단계에서 진행
- 번들 이미지 라이선스: Picsum Photos 경유 Unsplash 사진 — 출처 표기 검토 필요
- 디지털 상품 결제 시 Play Billing 사용: 해당 없음 (IAP 없음)

## 7. 검증 기준
- 자동: `npm run build` 성공 (tsc + vite build, 통과 확인), `npm test` — vitest 14/14 통과
- 대조: `npx vite preview` 로 HTTP 200 서빙 확인, 번들 이미지 3장·manifest 정상 로드 확인
- 주관: **미실시** — 실기기/에뮬레이터 드래그 제스처 동작은 검증 불가 (Android SDK 미설치,
  브라우저 인터랙션 미검증). 검수 단계에서 실기기 스모크 테스트 필요
- **검증 불가 항목**: 핀치줌/드래그 제스처의 실제 터치 동작, `npx cap add android` 이후
  APK/AAB 빌드 (이 서버에 Android SDK 미설치)
