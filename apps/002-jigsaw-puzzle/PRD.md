# PRD — 직소 퍼즐 (Jigsaw Puzzle)

> ⚠️ **파이프라인 예외 기록**: 이 앱은 표준 절차(수요발굴→PRD→app-scaffold)를 거치지 않고
> 채팅 세션에서 장르·스택을 먼저 정하고 바로 구현한 뒤 소급 작성된 PRD입니다.
> **템플릿도 `react-vite-capacitor`가 아니라 Flutter**로 만들어졌습니다 — 이미 만든
> 조각-생성 엔진(커스텀 Path 클리핑)을 웹/Capacitor로 다시 구현하는 비용이 커서
> 그대로 유지했습니다. `scripts/smoke_check.ps1`, `/build-android`, `/smoke-test`는
> 이 앱 구조를 그대로는 지원하지 않을 가능성이 높습니다(Capacitor 전제) — 검수 단계에서
> Flutter 전용 절차(`flutter build apk`/`appbundle`)로 대체해야 합니다.

## 1. 목적·타깃
- **문제**: 심심할 때 가볍게 시간 보낼 캐주얼 직소 퍼즐 게임이 필요하다
- **타깃 사용자**: 캐주얼 퍼즐 게임을 즐기는 일반 사용자 (연령 무관)
- **지역/언어**: 한국어 우선 (UI 텍스트 전부 한글)
- **수요 증거 링크**: (없음 — 소재는 대화 중 인간이 직접 지정: "퍼즐 → 직소 퍼즐")

## 2. 핵심 기능
- F1: 난이도 선택 (20 / 54 / 96 / 150 피스 — 1000피스는 모바일 터치 조작 부담으로 제외)
- F2: 이미지 선택 (앱 기본 번들 사진 3장 — Picsum/Unsplash 무료 라이선스)
- F3: 실제 요철(탭/블랭크) 모양의 직소 조각 — 드래그 & 정답 위치 스냅
- F4: 핀치 줌/팬(InteractiveViewer)으로 큰 피스 수도 조작 가능
- F5: 완성 시 소요시간 표시 (조각수/경과시간 상단 표시, 완료 다이얼로그)

## 3. 화면 목록
- 홈 화면: 이미지 3장 그리드 선택 + 난이도 ChoiceChip 선택 + 시작 버튼
- 퍼즐 화면: 보드 영역 + 흩어진 조각(트레이) + 상단 진행률/타이머

## 4. 데이터 모델
- 서버/영속 저장 없음 (세션 내 진행 상태만 메모리 보관, 앱 재시작 시 초기화)
- 조각 레이아웃은 매 판 결정적 생성(`generatePuzzleLayout`) — 필요시 seed로 재현 가능

## 5. 수익화
- 현재 미구현 (광고/IAP 없음) — MVP는 무료 플레이만
- 추후 완성 시 전면광고 1회 노출 정도가 자연스러운 위치 (Phase 2 후보)

## 6. Play 정책 체크
- 개인정보방침: 미작성 — 광고/수집 데이터 없으므로 상장 전 최소 형식 정책 페이지 필요
- 광고 포함 신고: 해당 없음 (광고 미포함)
- 콘텐츠 등급(IARC): 상장 단계에서 진행
- 번들 이미지 라이선스: Picsum Photos 경유 Unsplash 사진 — 출처 표기 검토 필요

## 7. 검증 기준
- 자동: `flutter analyze` 이슈 0건, `flutter test` 전체 통과 (현재 14/14 통과)
- 대조: 위 F1~F5 각각 수동 확인 필요 (에뮬레이터/실기기 미검증 — Android SDK 미설치 상태)
- 주관: 검수 미실시 (인간 검수 전 단계)
- **검증 불가 항목**: 실제 Android 기기/에뮬레이터에서의 드래그 제스처 동작, APK 빌드
  (이 서버에 Android SDK 미설치 — 별도 설치 필요)
