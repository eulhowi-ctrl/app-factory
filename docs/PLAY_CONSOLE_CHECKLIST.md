# Google Play 상장 체크리스트

> 매 앱 상장 전 이 목록을 순서대로 확인한다. **하나라도 미완료면 프로덕션 승격 금지.**

## 0. 계정
- [ ] Play Console 개인 계정 ($25 1회) — `apps/_accounts.md`에 기록
- [ ] 개발자 정책 동의, 계정 세부정보 완성 (주소·세금 등)

## 1. 앱 기본 정보 (Play Console → 앱 만들기)
- [ ] 앱 이름 / 짧은 설명 / 전체 설명 (영어)
- [ ] 아이콘 512×512 이상
- [ ] 피처 그래픽 1024×500
- [ ] 스크린샷 (휴대폰 2장+, 필요 시 태블릿)
- [ ] 카테고리·태그, 지원 언어 설정

## 2. 테스트 경로 (신규 개인 계정)
- [ ] **내부 테스트(Internal)** 업로드 → 자기 실기기 스모크 + **Pre-launch report** (크래시 0건 확인)
- [ ] **클로즈드 테스트(Closed)** 승격 — **12명 이상 테스터가 14일 연속** 참여 필수
  - ⚠️ 에뮬레이터는 집계 안 됨. Play 스토어 설치만 인정. 내부테스트는 카운트 안 됨.
  - ⚠️ 테스터가 12명 밑으로 떨어지면 타이머 리셋 → **14~20명 모집이 안전**
  - 💡 테스터 모집처 = `demand-research`에서 찾은 해외 커뮤니티 (검증 + 첫 사용자 채널)
- [ ] **Production Access Questionnaire** (~10문항): 테스터 참여도·피드백·개선 내용을 구체적으로 기재 (모호한 답변 = 거절 사유 1순위)
- [ ] 프로덕션 승격 신청 → 검수 통과 → 상장

> **현실적 일정**: 클로즈드 테스트 14일 + 리뷰 → 한 앱 "개발 완료→상장"은 **3~4주**. 그동안 앱 #2를 병렬 개발.

## 3. 기술 요건
- [ ] **targetSdk/compileSdk = 36** (2026-08-31부터 신규 제출 필수 — `version_bump.ps1`이 자동 강제)
- [ ] versionCode가 이전 업로드보다 증가 (자동화됨)
- [ ] 릴리즈 빌드가 dev `server.url`을 참조하지 않음 (`smoke_check.ps1`이 검사)
- [ ] AAB 서명 정상 (upload.keystore) — `android/keystore.properties` 사용

## 4. 정책 준수 (매 앱)
- [ ] **개인정보처리방침 URL** — `public/privacy.html`의 실링크 (앱 스토어 목록에 등록)
- [ ] **데이터 안전성 양식(Data safety)** 작성 — 수집 데이터·용도 신고
- [ ] **콘텐츠 등급(IARC)** 설문 완료
- [ ] **광고 포함 신고** (AdMob 있으면 반드시)
- [ ] 디지털 상품 결제("광고 제거" IAP) 제공 시 **Play Billing 필수** (2026-08-31 시행)
